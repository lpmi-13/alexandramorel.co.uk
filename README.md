# Alexandramorel.co.uk

The landing page for Dr. Alexandra Morel.

This is a static [Quarto](https://quarto.org/) website. Source content lives in
`index.qmd`; generated output is written to `_site/`.

## Local development

```bash
quarto preview
```

If using the project-local Quarto install from this checkout:

```bash
.tools/quarto-1.9.37/bin/quarto preview
```

Render a production build with:

```bash
quarto render
```
